# Frontend Design — Nüva One compatibility alias

The former Anthropic frontend-design skill is the conceptual predecessor to the current impeccable skill. Do not duplicate or revive deprecated instructions.

For any frontend implementation:
1. Load nuva-frontend-design and follow its Nüva product, brand, responsive and safety constraints.
2. Use impeccable as the canonical frontend design skill.
3. For dashboard and product UI, add interface-design; for design intelligence, add ui-ux-pro-max; for typography, add better-typography.
4. Extend the current Nüva design language rather than replacing it with a generic aesthetic.
