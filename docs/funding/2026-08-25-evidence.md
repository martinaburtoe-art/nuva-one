## 1. Sercotec — Capital Semilla Emprende

Official source verified 2026-08-25:
https://www.sercotec.cl/programas/capital-semilla-emprende/

The program supports the creation/formalization of new businesses. The current program page states a CLP 3,500,000 subsidy, with CLP 200,000–500,000 for business-management activities and up to CLP 3,300,000 for investments. The exact applicant contribution and regional focus are defined in each call's bases.

Eligibility baseline shown by the official program page:
- person aged 18+;
- no first-category SII start of activities;
- project must match the regional call focus;
- detailed eligibility must be checked against the active regional bases.

Important: this is not evidence that Nüva One is eligible. Eligibility depends on the active regional call, applicant status and formal/legal situation at the time of application.

## 5. Decision rule for Nüva funding claims

Never present a funding instrument as "available" unless all of the following are verified from the official source on the same application cycle:

1. call status is open;
2. opening and closing timestamps are current;
3. applicant type is compatible;
4. company age/start-of-activities requirement is compatible;
5. sales requirement is compatible;
6. territory requirement is compatible;
7. innovation/technology requirement is compatible;
8. co-financing requirement is compatible;
9. eligible expenses are compatible;
10. required documents are known;
11. official application URL is available.

Any missing item must remain `EXTERNAL EVIDENCE REQUIRED`.
