# Nüva One — Editorial Experience / media prompts

## Master direction

Create a premium editorial B2B visual world for Nüva One, a business operating platform for Chilean SMEs. Contemporary real businesses, believable people, natural daylight, tactile materials, restrained luxury, documentary photography, architectural composition, cinematic depth, subtle camera movement, realistic skin and materials, no futuristic clichés.

The visual reference is used only for pacing, oversized composition, continuity and scroll storytelling. Do not reproduce its photography, wording, branding or exact compositions.

**Never bake into generated media:** text, logos, UI labels, dashboards, charts, watermarks, fake app screens or interface copy. Web typography is layered separately.

## Continuity rules

1. Keep the same visual identity, lens language and grade across all scenes.
2. Prefer 35–50mm documentary perspective; use macro only for Scanner.
3. Movement must be slow enough to scrub cleanly: push, pan, lateral track, gentle orbit.
4. End each scene with a composition that can visually hand off to the next scene.
5. Generate masters in 16:9 for desktop; create a separate 9:16 crop when mobile art direction requires it.
6. Use first/last-frame or reference/ingredient workflows when generating connected sequences so environments and recurring people remain consistent.
7. Keep faces, products and brand-neutral spaces believable; Chilean context should feel natural rather than stereotyped.
