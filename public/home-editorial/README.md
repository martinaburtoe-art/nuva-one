# Nüva One — Editorial Experience assets

This directory is the media contract for `/experience`.

## Still-image slots

The experimental homepage works without media. When a file exists, the scene automatically uses it; when it does not exist, the CSS art direction remains as the fallback.

Use WebP for production stills:

- `hero.webp`
- `sales.webp`
- `customers.webp`
- `inventory.webp`
- `scanner.webp`
- `purchases.webp`
- `cash.webp`
- `shipping.webp`
- `finance.webp`
- `score.webp`
- `automation.webp`
- `studio.webp`
- `connections.webp`
- `final.webp`

Recommended master: 2400px or wider, 16:9, high-detail editorial photography, no baked text, no logo, no UI chrome.

## Visual continuity

Keep one Nüva visual world across all scenes: contemporary Chilean business environments, natural daylight, real materials, restrained premium styling, human presence where useful, believable operational details, and a documentary/editorial camera language.

Do not copy the reference site's photography or composition literally. The reference is only an interaction and art-direction benchmark.

## Video-ready contract

The current `/experience` route intentionally remains video-free. Future Veo/Flow masters should preserve the same scene IDs and framing so stills can be replaced by video without changing the story engine.
